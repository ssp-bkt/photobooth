# chaechae (แชะแชะ) 📸

ถ่ายโฟโต้บูธออนไลน์ — ตู้ถ่ายรูปสติ๊กเกอร์บนเว็บ เลือกช่อง ถ่ายรูป (มีพร็อพติดหน้าแบบ AI) จัดรูป ปรับสี เลือกกรอบ ใส่สติ๊กเกอร์ แล้วเซฟเก็บไว้
ใช้ได้ทั้งคอมพิวเตอร์ มือถือ และ iPad: https://ssp-bkt.github.io/photobooth/
