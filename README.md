# Snap Booth 📸

ตู้ถ่ายรูปออนไลน์ — เลือกช่อง ถ่ายรูป (มีพร็อพติดหน้าแบบ AI) แล้วตกแต่ง ปรับสี ใส่สติ๊กเกอร์ แล้วเซฟเก็บไว้
ใช้ได้ทั้งคอมพิวเตอร์ มือถือ และ iPad

## สิ่งที่ใช้ (ใช้เชิงพาณิชย์ได้)
- กรอบ ลาย พร็อพ ทั้งหมดวาดด้วยโค้ดเอง
- Emoji: [Noto Color Emoji](https://github.com/googlefonts/noto-emoji) — SIL Open Font License
- ฟอนต์: Mali, Itim (Google Fonts) — SIL Open Font License
- จับหน้า: [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe) — Apache 2.0
